## 蜀道项目的rag优化方案路径

按知识库类别法规、制度、操作规程、应急预案、事故案例**构建独立向量库**，路由 Agent 先识别 query 意图，再定向检索对应向量子库

##### 分块策略的优化

1.分块大小可以动态调整，基于不同类型文档构建不同向量库首先分块

- 高密度文档：规章制度，操作流程等分块长度200-300字符，确保每一块分块聚焦一个知识点

- 低密度文档：通知，公告，案列等分块长度设置大一些500字符，避免分块过细
  
  

2.分块元数据增强，检索的时候将元数据的内容作为检索的限制条件，进一步缩小检索范围

##### 检索方式优化

1.稠密 + 稀疏混合检索 + RRF 融合

2.引入Reranker重排

3.元数据权重检索



###  测试数据集收集策略

1. **人工构造测试集**
   * 分 5 大类知识库构建问答对：法规类 80 条、制度类 80 条、操作规程 100 条、应急预案 70 条、事故案例 70 条，合计 400 条标准 Query + 标准答案分片
   * 覆盖简单直白提问、口语化转述、多意图混合提问、模糊歧义提问四类场景
2. **线上真实日志采集** 采集 AI 助手线上用户真实会话 Query，去重、人工标注标准答案参考分片，扩充真实场景测试集
3. **负样本补充**：添加跨库混淆 Query，验证路由 Agent 分库准确率

### 2. 核心量化评估指标（项目集成自动化测试脚本）

1. **路由层指标**
   * 意图分类准确率：Agent 正确识别向量库类别占比
2. **检索召回指标（核心）**
   * Recall@3：标准答案分片出现在检索 Top3 结果中的样本占比
   * Recall@5：标准答案分片出现在检索 Top5 结果中的样本占比
3. **检索精准指标**
   * Precision@3 / Precision@5：Top3/Top5 分片内有效相关分片占比
4. **生成效果指标**
   * 答案幻觉率：输出内容无知识库依据的问答样本占比
   * 回答完整度：覆盖用户全部提问要点的样本比例

### 3. 自动化评估流程

每次更新向量库、调整分块策略、修改检索参数后，自动运行测试集脚本输出指标报表，作为 AI 技术方案文档核心附件。
